# Electricity Billing System

## Project Overview
A Java-based desktop application developed to manage electricity customer details and calculate electricity bills.

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC

## Features
- Customer details management
- Electricity bill calculation using slab rates
- Paid and pending bill status
- MySQL database connectivity using JDBC

## Concepts Used
- Object-Oriented Programming (OOP)
- Exception Handling
- Database Connectivity

## How to Run
1. Install the Java Development Kit (JDK).
2. Set up the MySQL database and required tables.
3. Configure the database connection.
4. Run the main Java class.
